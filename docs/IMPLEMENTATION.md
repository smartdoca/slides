# EPPT 实现与验收记录

目标：React / TypeScript npm 编辑器，Leafer 画布、Slate 富文本、Yjs 协同，面向 PPTX 的语义模型。

## 实施顺序

1. 修复原型的数据覆盖、readonly 闭包、文本尺寸、初始化和保存状态缺陷。
2. 模型命令、页面管理、稳定排序、元素插入删除复制、属性和用户级撤销。
3. Slate / Yjs 字符级绑定，统一文字显示与编辑样式。
4. 完整编辑工作台、快捷键、缩放、图层、备注和放映。
5. PPTX 导入导出与明确的兼容性报告。
6. 协同握手、ACK 故障、远端无回声、快照恢复等测试。
7. npm 打包安装验证及浏览器交互验收。

## 验收原则

测试仅使用示例文档。构建通过不代表协同或 PowerPoint 视觉兼容通过。
PPTX 支持矩阵必须标明可编辑、仅保留、降级和未实现的能力；不能把 PNG 幻灯片称为完整可编辑导出。
真实 Office 软件验证与本地结构测试分别记录。

原型已有的三个单元测试仅覆盖基础 map roundtrip、单向同步及 outbox 顺序；不代表多人文本、重连或服务端落库已验证。

| npm | ESM/CJS/类型/CSS 与子路径 | 安装真实 tgz 到独立临时项目；非 UI 子路径 Node smoke、tsc、根 UI 浏览器加载通过。根入口不支持 SSR |
