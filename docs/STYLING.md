# 飞书式样式操作

2026-10-16。以用户已登录的飞书幻灯片页面作为操作参考，重做选中对象后的格式入口。面向桌面编辑，主要链路是：选中文字或对象 → 浮动栏执行常用修改 → 点击“格式”展开精确属性 → 继续编辑或撤销。采用参考页的蓝色选中态、灰色图标、44px 浮动栏、294px 属性面板和圆形色板，不复制知识库、账号、分享等宿主业务界面。

## 已实现的操作

| 区域 | 行为 |
| --- | --- |
| 浮动格式栏 | 撤掉常驻第二行样式栏，浮动栏跟随选区和拖动；顺序为文字预设、字体、字号、对齐、列表、加粗、链接、字色、高亮、格式刷、格式和更多。侧栏打开且画布变窄时，字号/字体收进已展开侧栏，保留常用图标，避免裁掉格式按钮。 |
| 文字预设 | 大标题、标题、副标题、正文、小号正文五档。光标所在段落可整体应用，范围选区保留范围；字号步进每次一磅，直接输入支持 6–200 磅。 |
| 字体 | 搜索、文稿使用过的字体、推荐字体；字体渲染取决于设备安装情况。 |
| 对齐与列表 | 左/中/右对齐、增加/减少缩进；无列表、无序、有序列表；侧栏另有文字垂直对齐、行距和段落间距。 |
| 色板 | “字体颜色 / 高亮”双标签、文稿使用色、8×4 圆形基础色、无颜色、自定义六位十六进制；方向键移动、Esc 关闭，无效值保留错误。 |
| 格式面板 | 位置大小与旋转、对象对齐与层级；字体、粗体/删除线/斜体/下划线、字色与高亮；段落、行距、字间距、独立四边文字边距、背景与不透明度。文字、形状与其他对象共用几何控件。 |
| 格式复用 | 单击格式刷用一次、双击连续用、Esc 退出；更多菜单和右键菜单提供复制/粘贴格式、清除格式，保留 `⌘/Ctrl Shift C/V`。更多菜单保留上下标。 |
| 形状 | 六种预设、填充、轮廓与宽度；形状和直线可互刷轮廓样式。 |
| 右键菜单 | 剪切、复制、粘贴、删除，层级/对齐子菜单，组合、锁定、样式和设置格式。复制只更新本地对象剪贴板，粘贴后可一步撤销。 |

窄窗口适配以 1024×768 为验收尺寸；也在当前 856px 宽的 Codex 预览中走查。主编辑区域由上向下布置，减少原先画布上方的大块空白。精简重复的常驻样式组、顶部页面复制/分节入口和属性内重复几何标题；页面菜单保留对应能力。

## 模型、协作与宿主边界

- 每次批量设置是一笔本地 Yjs 事务和一个撤销步骤，不替换 `Y.XmlText` 或文字内容。只读不写文档；批量样式跳过锁定对象。
- 格式刷复制字符、段落与文本框外观，或形状/直线外观。复制不修改文档，不复制文字、链接目标、位置大小、分组、锁定、动画；清除格式保留链接语义。
- 对文字范围粘贴仅设置字符和段落；对文本框还设置背景、边距、垂直对齐与不透明度。混排格式以源的首段/首个 run 或当前文字选区为样本，不逐段复制混排结构。
- 新增可选 `TextLeaf.letterSpacing`（磅）和 `TextElement.paddingInsets`（上下左右 CSS 像素）；未设置的边仍回退到旧标量 `padding`。文档 schemaVersion 保持 2，无迁移；旧文档保持原值。
- 四边边距按字段存入现有 Y.Map，既有边距映射上的并发不同边修改可独立合并。首次并发创建映射遵循现有 Yjs 嵌套映射冲突规则。
- 展开/搜索/颜色历史/格式刷模式/剪贴板均为本地 UI 状态。未新增网络服务、鉴权或持久化通道。
- 宿主继续拥有资源、评论、导入导出与权限；组件 props 和 handle 契约不变。根入口与 core 导出样式工具，控制器支持批量样式、清除和字号步进。

## 文件交换与范围

PPTX 支持独立四边文字边距和字间距读写，保留透明填充、透明轮廓和 `a:noFill`。自动验证结构与重新导入后的语义；未做真实桌面 Office/WPS 的视觉验收。

这轮对齐的是常用样式操作，不能视为飞书全部能力的完整复刻。AI 编辑、云字体上传、文字转公式、自动适配、文字轮廓/阴影/反射、主题母版继承、渐变/纹理/三维和艺术字未实现。没有为这些能力放置无效入口。对象剪贴板属于当前工作台，不是飞书或系统剪贴板互通。

## 视觉、动效与证据

- 交互反馈：120ms 按钮选中态；状态切换：110ms 色板/格式面板淡入；首次出现：140ms 画布与 110ms 首次选区工具栏淡入。遵循 reduced-motion。避免装饰性循环或位移动画干扰编辑。
- 实际证据根目录：本地验收归档（不随 npm 包发布）。
- `feishu-final/`：1440×900、1024×768 的色板与浮动栏；`feishu-panel-final/`：桌面和窄窗口格式面板；`feishu-200/`：200% 细节。
- `feishu-motion/record.mp4` 及 start/mid/end：选中对象、加粗切换、打开色板；`feishu-entry/record.mp4`：初次画布出现。动效探测的交互透明度变化为 1；启动探测未捕获异步文档挂载后的首次出场，保留录屏复核。单屏编辑器不适用滚动叙事检查。
- 截图工具只报告 demo 缺少 favicon.ico 的 404；没有为此修改宿主配置。
