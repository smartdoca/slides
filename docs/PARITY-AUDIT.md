# PPT 能力与易用性差距审计

2026-09-13：页面批量操作/隐藏/分节/大纲及文字编号/缩进/间距/内边距/上下标/安全外链已有新增实现，见 [在线编辑清单](ONLINE-EDITING-PLAN.md)。下表是此前差距基线，不代表这些新增能力仍全部缺失；整体尚未完成。

审计更新：2026-09-12。对象：当前 `@eppt/editor` 源码和本地在线 Demo。结论：**尚未全面对齐，不能最终验收**。本表是工程实施与验收清单，不是对整个 OOXML 规范的穷举认证，也不提供没有明确分母的“完成百分比”。第三轮证据见 [画布直接编辑增量](DIRECT-EDIT-INCREMENT.md)。

## 对齐目标和判定方式

三个目标分别验收，不能相互替代：

1. **文件语义与保真**：PPTX 包、PresentationML / DrawingML 对象、关系与继承，能够编辑和往返，不只是生成可打开的 ZIP。依据 [ECMA-376](https://ecma-international.org/publications-and-standards/standards/ecma-376/)；当前没有做全量 XSD/Strict/Transitional 合规验证。
2. **产品能力**：以常用 PowerPoint 桌面编辑、放映、协作工作流为目标，而不是把“标准 PPTX”当成软件功能清单。微软也分别列出 Windows、Mac、Web 的能力差异，其[平台比较表](https://support.microsoft.com/en-us/powerpoint/compare-powerpoint-features-on-different-platforms)明确不是完整清单。不能因网页版缺某项就从本项目目标中删掉。
3. **易用性与可靠性**：完成真实编辑任务、键盘和鼠标路径、撤销、并发、重连、只读、窄窗口、失败恢复后才能通过。按钮存在或模型单测通过不等于用户路径验收通过。

状态含义：**部分**＝已有子集但有关键差距；**缺失**＝尚无完整实现；**待验**＝实现存在但证据不足。每一行未满足验收门槛前保持开放。生产宿主权限不能靠演示服务器替代。

## 本轮已修复及证据

1. **混合类型图层错序**：手写最小 OOXML 语义夹具复现 `shape/line/shape` 被读成 `shape/shape/line`；按源 `spTree` 子节点顺序恢复。支持对象的名字一并保留。嵌套组和未知对象仍不支持。
2. **直线/箭头**：识别预设直线，保留三角末端箭头；画布/缩略图/放映共享几何路径，新增箭头开关。1 px 高线条的 HTML 预览不再裁掉箭头。特殊双端箭头仍不支持。
3. **文字读取**：保留段内 run、软换行和文本域显示值的原始顺序；合并段落默认字符样式。动态域不会自动更新，明确报告降级。
4. **损失提示**：导出平面组合提示拆为独立对象；导入带文字形状背景/轮廓、渐变/效果和动态域时补充提示。报告仍为 best-effort，不保证穷尽所有不支持特性。
5. **查找与替换**：原字符串上匹配，防止 Unicode 大小写转换改变 UTF-16 下标；转义查询元字符。新增上一/下一循环、单项替换、Ctrl/⌘ F、Enter/Shift Enter、Esc 和焦点恢复；遵守 readonly 与本地撤销。尚未实现字符范围高亮。
6. **大于视口的画布**：改为可溢出的自动边距布局。100% 下实测 scrollLeft/Top 为 0，画布左上角在视口内，向右/下有滚动范围，不再被居中到负坐标。

回归代码：`src/pptx.import.test.ts`、`src/pptx.test.ts`、`src/model/anchors.test.ts`、`src/model/line.test.ts`。最小 OOXML 夹具不是完整标准符合性测试文件。

本地隔离浏览器文稿 `test-parity-audit-01`：两页查找、2/2→1/2 循环、反向导航、单项替换、关闭后立即撤销、只读查找可用且两种替换禁用；箭头在画布与放映显示；只读新页面读取到已保存内容。未修改用户 `demo` 房间。
