# 画布直接编辑增量

日期：2026-09-12。修复用户指出的表格操作、文字颜色和图层入口，并继续补齐此前交互清单。不是全量飞书复刻或 PowerPoint 完成认证。

## 本次实现

- 表格：选中后点击单元格直接输入；Enter/Tab 提交并移动、Shift+Enter 换行、Escape 取消。上/下插行、左/右插列、删除当前行列，右侧/底部加号追加，专用手柄拖动整个表格。结构命令与单元格提交各有独立撤销。冲突草稿不会覆盖已收到的远端内容。
- 文字：对象附近设置文字颜色、字符高亮、整个文本框背景，预置色/自定义色/清除；编辑状态保留 Slate 局部选区。三种颜色可原生 PPTX 往返。
- 图层：对象右键置顶/上移/下移/置底、复制、组合/取消、锁定/解锁、格式；键盘菜单导航和 Shift+F10。右侧仅保留可折叠选择窗格，不再作为图层顺序的必经入口。
- 形状：25 种分类预设，基础多边形、星、心、水滴、标注和方向箭头；Leafer、预览、PPTX 使用相应几何。没有完整自定义路径/调节点或形状内文本。
- 吸附：拖动到页面/对象边缘和中心、相邻对象等距参考；按屏幕缩放计算容差，Alt 暂停、设计菜单开关。拖动预览不写协作，结束提交一次。
- 图表：八种插入预览；柱/线支持最多 12 系列、100 分类，编辑系列名称/数据/颜色；簇状/堆积/百分比，普通/平滑/阶梯折线，标题/图例/数值标签。饼/环仍单系列。图例明确设置列数，避免静态 SVG 只显示第一页。
- PPTX：多系列、堆积、百分比、平滑线和 25 种原生预设形状往返；阶梯线导出为原生普通折线并明确报告，不能称无损。

## 协作和宿主升级

遵循 doca-collaboration 和 doca-editor-integration：宿主拥有权限、资源、传输、评论业务；不另建服务存储路径，不改变当前 Y.Doc/epoch。

根 schemaVersion 保持 2；握手新增 codecRevision **3**（协议版本仍 1）。客户端与验证端必须一起升级，缺失/不兼容 revision 显式拒绝。旧包不能处理表格操作和新增形状/图表语义，不允许静默混用。

表格保留初始 `cells`；每个结构/单元格操作以元素 Y.Map 的独立 `table-op:<id>` 字段保存，包含稳定行列标识、Lamport 序号和不可变内容。投影排序不依赖本地语言。不同格与插入行列可以合并，同一格字符串采用确定性最后写入。删除保留锚点；并发删空后留下确定性空白格；复制建立独立基线和 ID。`patchElement` 禁止重写表格 cells/rowIds/columnIds，应使用 `tableCommand`。当前未做操作日志压缩。恢复必须使用完整 Yjs checkpoint，不可将最新投影 cells 与旧操作重新组合，也不可用 JSON 重建现有协作文档。

图表数组仍整块提交，不是细粒度协同数据表。UI 会检测已收到的远端数据变化并要求重置草稿；不承诺两个真正同时的数据替换均保留。表格/图表上限是输入保护，不等于大数据性能认证。
