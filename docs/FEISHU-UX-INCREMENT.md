# 飞书参考交互与 AntV 图表增量

日期：2026-09-12。参考用户提供的六张截图，不复制品牌标识、图片资产，不宣称完整复刻飞书或 PowerPoint。

## 已实现

### 工作台第二轮优化

- 默认单排图标工具栏，文件/编辑/设计归入文稿菜单，撤销/重做和放映常驻。220px 页面栏与工具栏左区对齐，画布留白 32px，备注默认压缩为 48px，支持拖动和键盘调高。1280×720 预览中无属性面板时画布约 821×462px。
- 格式浮层跟随选中对象，按旋转包围盒定位，优先上方、空间不足放下方，并限制在可见画布内；对象拖动时隐藏，滚动与缩放后重新定位。选择框统一蓝色。
- 缩略图改用指针排序（浏览器原生拖放在当前预览环境未稳定触发，已替换），6px 拖动阈值、前后落点、边缘滚动、取消不写入。页面菜单支持复制、命名、移到开头/末尾和删除；F2 命名，Shift+F10 打开，方向键选择菜单项。
- 新建菜单提供深/浅色空白、封面、目录、双栏内容。这是显式插入独立可编辑对象，不是母版/版式继承，也不会替换已有页。
- 图表面板使用可视预览，属性面板优先展示逐行数据网格；应用前校验，遇到协作者更新时阻止旧草稿覆盖，允许重置到最新值。仍为单系列整块数据提交。
- 几何数值和快捷字号支持编辑草稿，Enter/失焦提交、Escape 取消，负数和小数可输入；只读切换丢弃未提交草稿。修复进入文本编辑时尚无光标范围导致首个格式命令无效的问题。

- 插入栏使用图标与文字分组；形状和图表选择面板；点击外部/Esc/移出焦点关闭。未支持的媒体、公式不展示空按钮。
- 默认收起右侧属性，扩大画布；文本和图片选中时出现对应快捷工具栏，共用模型/Slate 命令；保留完整开始、设计、动画、文件工具。
- 缩略图拖动到目标页前/后、落点线、边缘滚动、当前页身份不随序号改变；Alt + 上下移动，普通方向键/Home/End 导航。拖放产生一个本地撤销步骤，取消/只读/无效落点不提交。
- `moveSlideBefore(id, beforeId | null)` 仅改现有顺序，不重建幻灯片和 Y.XmlText。并发相同页移动沿用原顺序 CRDT 的确定性去重投影；不声称两个互斥落点同时生效。
- AntV G2 5.4.8 + SVG renderer，柱、线、饼、环四种单系列图。渲染按需加载、64 项内存缓存、失效异步结果不覆盖新画面；渲染容器在结束时释放。
- PPTX 生成原生图表及数据，新增饼/环往返。圆形图数据非负且至少一个正值，非法值在本地及验证端拒绝。

## 协作与包边界

资源、身份和服务仍由宿主注入，无第二套存储/上传。schema 2 增加图表枚举，不自动重建文档或 epoch。旧 bar/line 可读；新类型要求宿主客户端和验证端统一升级，不与旧包混用。图表数据仍整块提交，不是单元格 CRDT；UI 收起/展开、图表生成、页面导航不产生内容事务。
