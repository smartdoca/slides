# 表格操作增量

2026-10-16。参照相邻 `slatetsx` 工程的表格操作补齐日常编辑路径，沿用幻灯片中的原生表格对象、控制器和协同通道。

## 已实现

| 操作 | 行为 |
| --- | --- |
| 选择 | 点击进入单元格；拖动或 Shift 扩展矩形；行头、列头和左上角分别选择整行、整列、整表。选区跨合并格时扩展到完整区域。 |
| 输入与导航 | 单元格直接编辑；Enter 在文本内换行，Tab / Shift Tab 按可见单元格跳转，最后一格 Tab 自动增行；Ctrl/⌘ Enter 提交并下移。选择模式支持方向键、Home/End、Shift 扩选、Delete 清空、Ctrl/⌘ A 全选。Esc 取消当前草稿。 |
| 结构 | 当前区域前后插入行列、批量删除行列、合并与拆分。合并按行优先把非空内容用换行连接到左上角；拆分保留左上角的全部内容；撤销合并恢复原单元格。 |
| 剪贴板 | 原生复制、剪切、粘贴 TSV、HTML 表格及包内格式；支持单元格内引号、制表符和换行。矩阵粘贴可以扩展行列，覆盖合并区域时先拆分；单值可填满选区。包内复制保留整格样式和合并几何。 |
| 样式 | 选区统一设置字体、字号、粗体、斜体、下划线、文字颜色、背景色、水平与垂直对齐；混合值显示未统一状态；清空内容保留样式。 |
| 尺寸 | 拖动或用键盘调整行高/列宽，内边界重新分配相邻尺寸，末边界调整整体尺寸；也可平均分配。拖动过程仅预览，释放时写入一次。合并区域内部不会被不可见尺寸手柄拦截。 |
| 入口 | 表格上方的上下文工具栏、行列头、右键菜单；工具栏按视口定位，不跟随表格旋转。宿主评论操作继续注入同一工具栏。 |
| 撤销与恢复 | 每个区域命令一个撤销步骤；剪贴板读取后若选区变化或组件卸载则取消粘贴。旧草稿与远端新值冲突时拒绝覆盖；远端删除编辑行时保留可复制的草稿提示。 |

单元格仍保存纯文本，格式应用于整格。尚未实现字符范围富文本、同格字符级协作、链接/内联对象、公式、逐边边框和独立单元格边距，因此不能称为 `slatetsx` 全部能力的等价实现。真实系统中文 IME 尚未完整验收；组合期间禁止 Tab 提交的保护有自动测试。

## 数据与宿主契约

- `TableElement` 增加可选 `cellStyles`、`merges`、`columnWidths`、`rowHeights`；旧表格缺省字段不触发写入或迁移。`schemaVersion` 仍为 2。
- 保留不可变 `cells` 基线及稳定行列 ID。`EditorController.tableCommand` 写入独立操作，投影生成当前表格；通用元素 patch 不得覆盖表格数据、结构或样式矩阵。
- `TableCommand`、`TableClipboard` 和投影/选择工具从根入口与 `core` 导出。`cell` 命令可带 `expected` 检查旧值；`resize` 可带 `extent` 同步调整外框，保持一次事务和撤销。
- 不同行列/单元格及样式字段可分别合并；同一字段按逻辑时钟和操作 ID 确定顺序，不是字符级 CRDT。重叠合并矩形确定性地扩展为共同区域；合并后对被覆盖格的并发写入保留在底层数据中，可拆分读取。
- 单次剪贴板限 100×100、每格 100,000 字符、总计 1,000,000 字符；无效原生版本明确拒绝。HTML 通过 inert template 读取，仅提取文字和白名单整格样式，不加载图片/iframe/脚本。
- 内容继续使用现有 Yjs origin、outbox、epoch、checkpoint 和持久 ACK；选区、菜单、缩放、拖动预览及剪贴板缓存是本地视图状态。readonly 和锁定由控制器再次校验。
- 新操作要求 **`codecRevision: 6`**，协议仍为 1。包会话与本地演示服务器已同步严格协商；旧 revision 明确拒绝，不能让旧客户端忽略新表格操作。持久快照和历史不重置。
- 初次交互验收时未发布 npm 包；后续发布范围见 [0.3.0-alpha.3 发布说明](releases/0.3.0-alpha.3.md)。Doca 生产宿主未升级。接入方必须同步升级客户端和服务端 codec 能力，并沿用自己的身份、ACL、资源和保存服务；本地 demo 验收不能替代生产接入。

## 显示与文件交换

画布、缩略图、放映和打印预览共享 `TableGrid`。SVG foreignObject 中显式使用 XHTML 小写 `rowspan` / `colspan`，避免退出编辑后合并格显示错位。只读表格不创建编辑覆盖层或工具栏。

PPTX 原生表格读写覆盖合并、整格样式、行高、列宽和透明背景；没有把表格栅格化。如果被覆盖格包含后到的协作内容，导出拆开相应合并区域并报告提示，以保留所有文字。自动验证了 OOXML 和重新导入语义；没有完成真实 Office/WPS 打开、编辑、保存后的视觉对照。

缩放控件的文本 `⌄` 已换成固定尺寸 SVG，并提供 25/50/75/100/150/200% 与“适应画布”菜单。打开菜单不改变比例；缩放不写文档。
