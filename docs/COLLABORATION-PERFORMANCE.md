# 大文稿协同压测 · 0.2.1

2026-09-13，本机 macOS / Node 24.15，隔离生成的中文文本，500 页 × 20 元素及 100 页 × 100 元素。比较已安装 0.2.0 与 0.2.1；不代表 Doca 生产连接、弱网、多图片/图表、多人高频编辑或百万对象性能。

## 优化范围

- 每个 Y.Doc 共用一个局部只读投影，按 Yjs 变更目标及祖先失效；未变页/元素保持引用，不再每次改字解析并 stringify 全部元素。公开 readDocument 仍为独立读取，命令事务内不用陈旧缓存。
- 单页命令只读取目标页；画布不因其他页面编辑重绘，静态文本 SVG 不因选区变化重复生成。
- 缩略图仅渲染视口及上下 240px 范围，离屏卸载；保留轻量行、键盘导航和拖拽目标。打印 DOM 仅在 beforeprint 到 afterprint 间存在。
- 本地示例服务复用隔离校验副本，校验仍覆盖全部模型；拒绝/落盘失败丢弃副本。权威正文仍只在 SQLite COMMIT 后推进并 ACK；无用户连接后释放校验副本。没有新增保存通道。

## 复现

运行 `node scripts/collaboration-performance.mjs /绝对路径/已安装包/dist/core.js`：两个内存 Y.Doc、80 次双向编辑及缩略图失效，不含网络/渲染。实际服务运行后，`EPPT_PERF=1 EPPT_TEST_ORIGIN=ws://127.0.0.1:5180 yarn test src/collaboration/performance.integration.test.ts`：新建 test-perf-* 文稿，500 页、9981 文本对象、30 次双向写入，等待真实 ACK 和远端更新；不操作用户文稿。

| 场景 | 0.2.0 编辑中位 / P95 | 0.2.1 编辑中位 / P95 |
| --- | --- | --- |
| 100 页 × 100 文本 | 132.24 / 143.89 ms | 0.53 / 1.09 ms |
| 500 页 × 20 文本 | 139.39 / 146.25 ms | 0.37 / 0.89 ms |

两端收敛，80 次变更合计 2962 bytes。这里测的是元素颜色命令及远端投影，不把它说成中文输入法延迟。初始化两副本及缓存约 0.33–0.43 秒；不能据此声称加载加速。

### 本地真实 WebSocket + SQLite FULL 同步落盘

500 页 / 9981 元素 / 30 次双向更新：原服务 ACK 中位 253.96 ms、P95 293.02 ms；优化后中位 42.67 ms、P95 51.93 ms。验证远端收敛及重复 ACK。属于示例服务优化，不是 npm 包自动替换 Doca 服务端；生产宿主需要独立对接与压测。

回归包含局部缓存失效、中文/格式嵌套文本、表格结构、删页/撤销、复制/排序、checkpoint、只读、资源失败、打印按需挂载、离屏卸载及拖拽目标保留。服务端验证非法更新后合法编辑仍可保存。

浏览器 500 页文稿连续 60 秒执行选区定位、跨页滚动、属性面板切换，正文更新 **0**，稳态 7 个预览、4020 个 DOM 节点，无页面错误日志。该段没有导出动作；文件导出不写正文由独立既有回归覆盖。

## 边界

模型校验仍限制 500 页、每页 2000 元素；它们是拒绝阈值，不是这些上限可以任意组合的流畅承诺。本轮覆盖总计约 1 万文本元素，不承诺单页 2000 个复杂图表/大图片。PPTX 30 MiB、解压后 60 MiB、10000 ZIP 条目、单图上传 10 MiB 的限制不变。

首次全量同步/全文导出/打印仍需处理整份文稿；示例服务仍对每次更新生成完整 checkpoint 并落盘，因此文件越大保存确认越慢。校验副本增加活跃房间内存占用；Node heap 差值受 GC 影响，不作为峰值内存或容量规划数据。仍待生产环境长时间多房间、多用户和资源混合压测。

遵循 doca-collaboration / doca-editor-integration：schema 2、codec 4、epoch 及原始 CRDT 身份不变；不清空浏览器/用户文档，不伪造 ACK，不增加自动保存通道。旧 0.2.0 包保留，可在同一 codec 4 文稿回滚；0.1.0 不可混入 codec 4 会话。
