# 0.3.0-alpha.3

2026-10-16 · Preview release · MIT

## Changes

- Contextual formatting tools following the inspected Feishu Slides workflow: text presets, searchable fonts, color/highlight palettes, Format Painter, and an optional format sidebar with independent text margins and character spacing.
- Table rectangular/row/column selection, merge/split, matrix clipboard, whole-cell styles, row/column resizing, merged-cell navigation and automatic final-row insertion with Tab. Commands retain native undo, readonly and conflict guards.
- Shared table rendering for editable canvas, previews and readonly views; fixed XHTML merged-cell attributes and hidden resize handles intercepting merged cells.
- Fixed the zoom arrow rendering and connected it to percentage presets and Fit canvas.
- Consolidated table menu commands, clipboard handling and resize logic without changing their behavior.
- Native PPTX support for the new text spacing, table merges, whole-cell styles, dimensions and transparent fills.

## Host compatibility

New table operations require **codec revision 6**. Upgrade client and server negotiation together; older revisions are rejected. Protocol version 1 and document schema version 2 are unchanged. Existing checkpoints, epochs and document identities are preserved without automatic migration.

This release does not upgrade the Doca production host. Identity, ACL, asset access, transport and durable persistence remain host responsibilities.

Table cells still contain plain text with whole-cell formatting. Character-range rich text and character-level collaboration within one cell are not implemented. Real Office/WPS visual roundtrips and complete system IME acceptance remain open.

## Validation

- TypeScript and the production ESM/CommonJS/declaration build passed.
- Full automated suite: 198 passed; the 3 opt-in integration cases were skipped in that run, including the real 60-second idle check among the passing cases.
- WebSocket/SQLite collaboration and PPTX-upload integration: 2 additional cases passed against isolated local demo rooms. The opt-in performance case was not run.
- Installed the actual npm tarball in an isolated consumer: ESM and CommonJS subpaths, public TypeScript types, table style/merge/undo and native PPTX roundtrip passed.
- Loaded the installed root React entrypoint and CSS in a browser: readonly workspace and table rendered without console errors.
- Package file inventory and `git diff --check` passed. Local demo databases, credentials, logs and dependency directories are excluded from the package.

Earlier interaction acceptance and remaining limitations are documented in [styling](../STYLING.md) and [tables](../TABLES.md). These checks do not establish real Office/WPS visual compatibility or production Doca integration.
