# 0.3.0-alpha.4

2026-10-21 · Preview release · MIT

- Adds `onImagePreview(event)` to the workspace and canvas editor, with stable current-image identity and an ordered gallery of native images across every slide in the same presentation.
- Edit mode selects an image first and previews on its next click or explicit preview action. Readonly and locked images preview on one click.
- Provides a standalone lightbox with previous/next navigation, horizontal drag/swipe and trackpad navigation, keyboard controls, zoom/pan, fit and resource retry. A supplied host callback takes precedence.
- Keeps resource authorization, URL resolution, protected asset access and downloads in the host. Preview events contain stable asset references, not resolved URLs.

See [the public image-preview contract](../IMAGE-PREVIEW.md). This change is view/API only: no stored format, schema, codec, epoch, checkpoint, outbox, transport, migration or old-data compatibility change. Protocol 1, schema 2 and codec revision 6 retain their current rules. The Doca host adapter is upgraded and verified separately.

Validation: TypeScript, ESM/CJS/declaration builds, 203 automated cases and 2 isolated WebSocket/SQLite and PPTX-upload integrations passed. The actual tarball passed public-type and ESM/CJS consumer checks plus browser preview/host-callback tests. A 113.768-second browser observation retained zero content transactions. Collaboration and PPTX CJS bundles and the persisted-model declaration file are byte-identical to the published alpha.3 artifact. The opt-in performance case and production Doca integration are outside this package verification. See [the verification record](../verification/image-preview-2026-10-21/README.md).
