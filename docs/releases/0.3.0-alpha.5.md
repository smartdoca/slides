# 0.3.0-alpha.5

2026-10-28 · Preview release · MIT

Comment cards can now temporarily shade their corresponding slide content through the controlled `PresentationWorkspaceProps.activeCommentId?: string | null` prop. The host supplies the ID of a current `commentMarkers` entry and owns activation, timeout, repeated-click restart and clearing. Existing `onCommentAnchorClick(candidates)` and `revealAnchor(anchor)` retain their responsibilities.

Multi-element anchors shade each surviving element separately. The overlay follows native position, size and rotation, including live drag/resize geometry, and disappears for deleted targets or removed markers. It works in edit and readonly views and stays outside printing, slideshow and native PNG/PPTX exports. Table anchors retain their whole-table scope; valid relative text anchors shade the whole text element. No new cell/glyph anchor semantics are introduced.

This release includes all previously verified Slides changes, including alpha.4 image-gallery previews and alpha.3 table editing. Canvas table connection ports belong to the separate Canvas package and are not claimed as a Slides capability.

No document model, persisted anchor, protocol, schema, codec, checkpoint, epoch, history, outbox, compatibility reader or migration changes. Protocol 1, schema 2 and codec revision 6 keep their existing rules. Core, collaboration and PPTX CJS runtimes and persisted-model/codec declarations retain the alpha.4 bytes. Hosts install the official npm version and adapt the prop separately; this package release does not change Doca dependencies.

Verification: TypeScript and ESM/CJS/declaration builds; 207 passing automated cases with 3 existing opt-in integration/performance cases skipped; installed public types, CJS anchor checks and ESM/PPTX roundtrip. The isolated browser exercises controlled clearing, marker visibility, overlap callbacks, cross-slide reveal, zoom, edit/readonly changes, native table editing/undo and two-replica remote movement/deletion without echo. A 70.901-second pure-idle observation and 89.578-second view-operation observation each retained zero content writes.
